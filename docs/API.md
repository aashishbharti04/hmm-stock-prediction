# API Reference

Base URL (local): `http://localhost:8000/api/v1`

Interactive docs are auto-generated by FastAPI:
- Swagger UI → `http://localhost:8000/docs`
- ReDoc → `http://localhost:8000/redoc`

---

## `GET /health`

Liveness/readiness probe.

**Response `200`**

```json
{
  "status": "ok",
  "version": "1.0.0",
  "environment": "development"
}
```

---

## `POST /analyze`

Fetch market data, fit a Gaussian HMM, and return regimes + forecast.

### Request body

| Field           | Type   | Default | Constraints                                   |
|-----------------|--------|---------|-----------------------------------------------|
| `ticker`        | string | —       | 1–12 chars: `A–Z`, `0–9`, `.`, `-` (required) |
| `period`        | string | `2y`    | `1mo,3mo,6mo,1y,2y,5y,10y,max`                |
| `interval`      | string | `1d`    | `1d,1wk,1mo`                                   |
| `n_states`      | int    | `3`     | `2 ≤ n ≤ 8`                                    |
| `forecast_days` | int    | `5`     | `1 ≤ d ≤ 30`                                   |

```json
{
  "ticker": "AAPL",
  "period": "2y",
  "interval": "1d",
  "n_states": 3,
  "forecast_days": 5
}
```

### Response `200` — `AnalysisResponse`

```jsonc
{
  "ticker": "AAPL",
  "period": "2y",
  "interval": "1d",
  "n_states": 3,
  "currency": "USD",           // "DEMO" when synthetic fallback was used
  "as_of": "2025-09-17",
  "latest_close": 178.42,
  "latest_state": 0,
  "latest_state_label": "Bullish",
  "log_likelihood": 812.34,
  "prices": [
    {
      "date": "2024-01-02", "open": 150.1, "high": 151.0, "low": 149.2,
      "close": 150.6, "volume": 12000000, "log_return": 0.0033, "state": 2
    }
    // …downsampled to the most recent ~750 points
  ],
  "states": [
    { "state": 0, "label": "Bullish", "count": 86, "mean_return": 0.00395,
      "volatility": 0.0098, "frequency": 0.331 }
  ],
  "transitions": {
    "states": [0, 1, 2],
    "matrix": [[0.95, 0.03, 0.02], [0.05, 0.90, 0.05], [0.04, 0.03, 0.93]]
  },
  "forecast": [
    { "step": 1, "predicted_close": 179.1, "lower_bound": 175.2, "upper_bound": 183.0 }
  ]
}
```

### Error responses

| Status | Meaning                | When                                            |
|--------|------------------------|-------------------------------------------------|
| `422`  | Unprocessable Entity   | Invalid input, or too few observations to fit   |
| `404`  | Not Found              | No market data for the ticker (fallback off)    |
| `500`  | Internal Server Error  | Model failed to fit / unexpected error          |

```json
{ "detail": "Ticker must be 1–12 chars: letters, digits, '.', '-' only." }
```

## `GET /analyze`

Convenience wrapper using query parameters (handy for links/demos):

```
GET /api/v1/analyze?ticker=MSFT&period=1y&n_states=3&forecast_days=5
```

Same response shape as the POST endpoint.

---

## Examples

**curl**

```bash
curl -X POST http://localhost:8000/api/v1/analyze \
  -H "Content-Type: application/json" \
  -d '{"ticker":"AAPL","period":"2y","n_states":3,"forecast_days":5}'
```

**JavaScript (fetch)**

```ts
const res = await fetch('http://localhost:8000/api/v1/analyze', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ ticker: 'AAPL', period: '2y', n_states: 3, forecast_days: 5 }),
});
const data = await res.json();
```

**Python (httpx)**

```python
import httpx
r = httpx.post("http://localhost:8000/api/v1/analyze",
               json={"ticker": "AAPL", "period": "2y", "n_states": 3, "forecast_days": 5})
print(r.json()["latest_state_label"])
```
